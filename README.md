# Pocket Paws

An original, cozy pet-care browser game inspired by collectible toy pets. Adopt four friends, feed and cuddle them, customize their cottage, and catch treats to earn coins.

## Run

Requires Node.js 18 or later. No package installation required.

```sh
npm start
```

Open port 3000 in your browser. Set `PORT` to use another port.

Progress saves automatically in the browser's local storage. Feed costs 5 coins; play earns 10 and consumes energy. Nap restores energy. Catching treats earns 3 coins each, and leaving a round early banks caught treats. Room palettes are free. Sound is optional.

No external runtime dependencies. Google Fonts are optional; system fonts are used if unavailable.
